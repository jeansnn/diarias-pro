Um aplicativo web *mobile-first* simples, rápido e offline desenvolvido para o controle eficiente de serviços diários. Ideal para gerenciar rotinas de trabalho autônomo, safras, colheitas e produção agrícola, permitindo o acompanhamento preciso de valores a receber, histórico de atividades e geração de relatórios instantâneos.

---

## ✨ Funcionalidades Principais

* **➕ Registro Ágil:** Adicione diárias com data, descrição da atividade (com sistema inteligente de autocompletar baseado no histórico) e valor.
* **🌓 Tema Dinâmico:** Suporte nativo para Tema Claro (Light Mode) e Tema Escuro (Dark Mode), garantindo conforto visual em qualquer ambiente, seja no campo sob o sol ou à noite.
* **👁️ Modo Privacidade:** Com um simples toque, o aplicativo aplica um efeito de desfoque (blur) em todos os valores financeiros na tela, protegendo suas informações em locais públicos.
* **✅ Controle de Recebimentos:** Marque e desmarque serviços como pagos com facilidade. Os itens recebidos ganham destaque visual (riscados e em verde) para rápida identificação.
* **📊 Dashboard e Estatísticas:** Visão geral automática do mês atual, mostrando faturamento bruto, saldo pendente a receber e média diária.
* **📑 Relatórios e Exportação:** * Copie a lista de lançamentos de um mês específico formatada perfeitamente para envio via WhatsApp.
    * Gere um comprovante visual (estilo cupom) pronto para captura de tela (print) e prestação de contas.
* **💾 Funcionamento Offline:** Todos os dados são salvos no `LocalStorage` do navegador. Não requer internet ou banco de dados externo para funcionar.
